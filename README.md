# TurnoFacil

Microapp de reservas de turnos para negocios de servicios (peluquerías, barberías, estética, kinesiólogos, talleres).

Estado: MVP construido (Django + PostgreSQL), pendiente de QA y del primer deploy. Incluye registro e ingreso del negocio, servicios, profesionales con horarios, reserva online sin cuenta, emails de confirmación y recordatorio, reprogramación y cancelación por el cliente, y agenda con gestión de turnos en el panel.
