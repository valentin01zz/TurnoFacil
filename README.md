# TurnoFacil

Microapp de reservas de turnos para negocios de servicios (peluquerías, barberías, estética, kinesiólogos, talleres).

Estado: MVP en construcción (Django + PostgreSQL). Hecho: registro del negocio, ingreso, recuperación de contraseña, link público, servicios, profesionales con horarios y reserva de turnos.
