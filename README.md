# TurnoFacil

Microapp de reservas de turnos para negocios de servicios (peluquerías, barberías, estética, kinesiólogos, talleres).

Estado: MVP en construcción (Django + PostgreSQL). Hecho: registro del negocio, ingreso, recuperación de contraseña, link público, servicios, profesionales con horarios, reserva de turnos con email de confirmación, reprogramación y cancelación por el cliente, y agenda del día en el panel con carga, reprogramación y cancelación de turnos.
