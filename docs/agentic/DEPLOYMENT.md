# Deployment Checklist: [Proyecto / versión]

## Antes
- [ ] Informe de QA aprobado
- [ ] Variables de entorno definidas (fuera del repo)
- [ ] Migraciones de datos revisadas y con backup si aplica
- [ ] **Rollback documentado** (cómo volver atrás y en cuánto tiempo)
- [ ] OK del Founder

## Durante
- [ ] Despliegue ejecutado según el procedimiento documentado
- [ ] Verificación posterior (flujo principal funciona, sin errores en logs)

## Después
- [ ] Documentación de uso y despliegue entregada
- [ ] Cliente informado
- [ ] Qué costó trabajo o se repitió → `docs/registro-de-candidatos.md`
